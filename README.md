# fernstalonstudios.com

Static site for Fernstalon Studios, served by GitHub Pages at https://fernstalonstudios.com.

- `index.html` studio home, with the game development cycle background (`assets/dev-cycle.js`)
- `shacklefall/` game page and press fact sheet
- `privacy/` privacy policy for the game and the site
- `assets/` stylesheet, images, Pixel Frond logo and icons, Shacklecut font (SIL Open Font License, see `assets/fonts/OFL.txt`)

No build step: edit the HTML and push.
